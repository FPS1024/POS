# POS
# 超市收银 POS 系统

一个功能完整的超市收银系统：Vue 3 + Vite 前端，Node.js + Express + SQLite 后端。

## 功能

- 收银台：扫码/搜索加购、会员识别、折扣、多支付方式、找零、挂单/取单、小票打印
- 商品管理：商品档案、分类、条码、进价/售价、库存、CSV 导入导出
- 库存管理：采购入库、盘点调整、报损出库、库存流水、低库存预警
- 订单管理：订单查询、详情、退款退货
- 客户管理：会员档案、积分累计与调整、等级
- 数据报表：营收概览、销售趋势、品类占比、热销商品
- 系统设置：门店信息、税率、小票样式、操作员管理

## 快速开始

```bash
npm install
npm run dev
```

前端默认运行在 http://localhost:5173，后端 API 运行在 http://localhost:3001。

默认账号：

- 管理员：`admin` / `admin123`
- 收银员：`cashier` / `123456`

## 目录结构

```text
client/   Vue 3 前端
server/   Express + SQLite 后端
```
